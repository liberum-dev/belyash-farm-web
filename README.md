# Belyash Farm

A cozy browser farming game about growing crops, building production chains, completing deliveries, expanding your farm, and spending time with Belyash and his dog helpers.

## Play

**[▶ Play Belyash Farm 0.19](https://liberum-dev.github.io/belyash-farm-web/)**

No installation is required. The game runs directly in a modern web browser.

## Current Version

**0.19**

### Highlights

- Farming, crafting, and production chains
- Farm expansion and new areas
- Dog helpers and Belyash interactions
- Orders and deliveries
- Improved forests, roads, paths, and environment visuals
- Night lighting and seasonal Halloween content
- Improved planting, watering, and harvesting controls
- Desktop, mobile, and tablet browser support

## Saves

Browser saves are stored locally in the browser and device you use.

For important farms, use **Download save backup** in the game menu and keep the exported JSON file. Backups can later be restored with **Restore from backup**.
